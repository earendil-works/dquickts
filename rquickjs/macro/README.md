# rquickjs-sys

[![github](https://img.shields.io/badge/github-stencil--hq/dquickts-8da0cb.svg?style=for-the-badge&logo=github)](https://github.com/stencil-hq/dquickts)

This crate is a procedural macros for the high level Rust bindings for the [QuickJS](https://bellard.org/quickjs/) Javascript engine (the QuickJS tree this crate is vendored in).

**NOTE:** Do not use this crate directly in favor of [rquickjs](../README.md) crate.
